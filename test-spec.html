TODOアプリ テスト仕様書

対象: http://localhost:8080 / 開始時点で todos は5行

実施順: 上から順に実施

番号 確かめること 入れる値 期待する結果 結果 備考/NG
1 一覧画面を開くと、登録済みのやることが一覧で見える /todos を開く 一覧画面に5行のtodoが出て、列は「やること」「ジャンル」「優先度」「期限」「状態」「操作（編集・削除）」の順で見える。
2 一覧画面の上部に絞り込み・並び替え・新規登録の操作がそろっている 一覧画面の上部を見る 一覧画面の上部に、名前の入力欄、ジャンルの選ぶ欄、「絞り込む」ボタン、「期限が近い順」「期限が遠い順」のリンク、「新規登録」ボタンが出る。
3 一覧画面の優先度と状態が画面用の言葉で見える 一覧の各行を見る 優先度は「高・中・低」、状態は「完了・未完了」の言葉で出る。
4 初回表示の一覧は期限が近い順で並ぶ /todos を開く 期限が入っている行は、期限が近いものから順に上へ並んで出る。
5 新規登録ボタンから登録画面へ進める 一覧で「新規登録」を押す /todos/new が開く。
6 登録画面に5つの入力欄と2つのボタンがある 登録画面を見る 登録画面に「やること」「メモ」「ジャンル」「優先度」「期限」の5項目と、「確認する」「一覧へ」の2つの操作が出る。
7 やることが空のままだと登録に進めない やること: 空欄 / メモ: 空欄 / ジャンル: デザイン / 優先度: 高 / 期限: 空欄 登録画面のまま止まり、やること欄の下に「やることを入力してください」と出る。
8 やることに空白だけを入れても登録に進めない やること: 半角空白または全角空白だけ / メモ: 空欄 / ジャンル: デザイン / 優先度: 高 / 期限: 空欄 登録画面のまま止まり、やること欄の下に「やることを入力してください」と出る。
9 やることが256文字以上だと登録に進めない やること: 256文字の文字列 / メモ: 空欄 / ジャンル: デザイン / 優先度: 高 / 期限: 空欄 登録画面のまま止まり、やること欄の下に「やることは255文字以内で入力してください」と出る。
10 メモが256文字以上だと登録に進めない やること: テスト追加タスク / メモ: 256文字の文字列 / ジャンル: デザイン / 優先度: 高 / 期限: 空欄 登録画面のまま止まり、メモ欄の下に「メモは255文字以内で入力してください」と出る。
11 ジャンルを選ばないと登録に進めない やること: テスト追加タスク / メモ: 空欄 / ジャンル: 未選択 / 優先度: 高 / 期限: 空欄 登録画面のまま止まり、ジャンル欄の下に「ジャンルを選んでください」と出る。
12 優先度を選ばないと登録に進めない やること: テスト追加タスク / メモ: 空欄 / ジャンル: デザイン / 優先度: 未選択 / 期限: 空欄 登録画面のまま止まり、優先度欄の下に「優先度を選んでください」と出る。
13 正しい内容で確認画面へ進むと、入力値が文字で並び未入力欄は入力なしになる やること: テスト追加タスク / メモ: 空欄 / ジャンル: プログラミング / 優先度: 中 / 期限: 空欄 で「確認する」を押す /todos/confirm が開き、5項目が入力欄ではなく文字で出て、メモと期限は「（入力なし）」と出る。
14 登録確認の書き直すで、入れた値を保ったまま登録画面へ戻る 項番13の確認画面で「書き直す」を押す /todos/new に戻り、やること「テスト追加タスク」、ジャンル「プログラミング」、優先度「中」が入ったまま見える。
15 登録すると一覧へ戻り、登録完了の文と追加した行が出る やること: テスト追加タスク / メモ: 空欄 / ジャンル: プログラミング / 優先度: 中 / 期限: 2026-09-01 で確認後に「登録する」を押す 一覧画面の上に「登録しました」と出て、一覧に「テスト追加タスク」の行が増えて全部で6行になる。
16 名前で絞り込むと、やることに言葉の一部を含む行だけが残る キーワード: 追加 / ジャンル: すべて / 「絞り込む」を押す 「テスト追加タスク」を含む行だけが残って出る。
17 名前で絞り込んだ結果のアドレスに条件が付く 項番16の結果画面のアドレスを見る アドレスの後ろに、入力した絞り込み条件を表す文字列が付いている。
18 ジャンルで絞り込むと、同じジャンルの行だけが残る キーワード: 空欄 / ジャンル: プログラミング / 「絞り込む」を押す ジャンルが「プログラミング」の行だけが残って出る。
19 名前もジャンルも空で絞り込むと、全件が出る キーワード: 空欄 / ジャンル: すべて / 「絞り込む」を押す 絞り込まれず、一覧に6行すべてが出る。
20 絞り込み結果が0件のときは専用文ではなく未登録の文が出る キーワード: 該当しない文字列 / ジャンル: すべて / 「絞り込む」を押す 一覧に行は出ず、「まだ1件も登録されていません」と出る。
21 期限が遠い順のリンクで、期限が遅いものから並ぶ 絞り込みを外して一覧へ戻り、「期限が遠い順」を押す 期限が入っている行は、期限が遠いものから順に上へ並んで出る。
22 追加した行の編集画面で、今の値と完了欄が出る 「テスト追加タスク」の行の「編集」を押す /todos/{id}/edit が開き、登録の5項目に加えて完了のチェック欄があり、今の値が入った状態で出る。
23 編集確認画面で、直した内容が文字で出る やること: テスト更新タスク / メモ: 編集後メモ / ジャンル: 就職活動 / 優先度: 低 / 期限: 2026-09-05 / 完了: チェックあり に変えて「確認する」を押す /todos/{id}/confirm が開き、直した内容が入力欄ではなく文字で出る。
24 編集を保存すると一覧へ戻り、保存完了の文と更新後の値が出る 項番23の確認画面で「保存する」を押す 一覧画面の上に「保存しました」と出て、対象行は「テスト更新タスク」「就職活動」「低」「2026-09-05」「完了」で出る。
25 削除確認画面には消す行の3項目だけが出る 「テスト更新タスク」の行の「削除」を押す /todos/{id}/delete が開き、「やること」「ジャンル」「期限」が文字で出て、「消す」「やめる」が押せる。
26 最後に追加した行を削除して、todo件数を5行へ戻す 項番25の削除確認画面で「消す」を押す 一覧画面の上に「削除しました」と出て、「テスト更新タスク」の行が消え、一覧は5行に戻る。
